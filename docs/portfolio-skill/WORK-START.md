# WORK START — Token-Saver Protocol

Every Work round:

1. Read `CORE.md`
2. Read `registry.json`
3. Verify real current QA HEAD in GitHub
4. Load ONLY the task-relevant reference:
   - content → `references/content.md`
   - decisions → `references/decisions.md`
   - evidence → `references/evidence.md`
   - outcomes → `references/outcomes.md`
   - images → `references/images.md`
   - GitHub/CI → `references/execution.md`
   - QA → `references/qa.md`
5. Read the project-specific Work Order only.
6. Do not re-audit frozen topics not named in the Work Order.
7. Stop only for a TRUE repo conflict, content integration conflict, or generic shared capacity gap.

This file exists to reduce token usage. Do not load the full `SKILL.md` on every execution unless the task changes governance itself.
